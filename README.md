# 🏥 AI Medical Report Explainer

## 📌 Project Overview

AI Medical Report Explainer is a Streamlit-based web application that helps users understand their medical reports in simple language. Users can upload a PDF medical report, and the application uses the Groq LLM to generate an easy-to-read explanation.

## 🚀 Features

- Upload medical reports in PDF format
- Extract text from the report
- AI-generated explanation in simple language
- Highlights important findings
- Suggests general health precautions
- Advises when to consult a doctor
- User-friendly Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- PyPDF

## ▶️ How to Run

1. Clone the repository.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Add your Groq API key in `app.py`.

4. Run the application:

```bash
streamlit run app.py
```

## 📸 Output

The application provides a simple explanation of the uploaded medical report along with health precautions and recommendations.
