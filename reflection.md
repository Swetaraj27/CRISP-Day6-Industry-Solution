# Reflection

## What I Built

I developed an AI Medical Report Explainer using Streamlit, Groq LLM, and PyPDF. The application allows users to upload a medical report in PDF format and receive an easy-to-understand explanation.

## Challenges Faced

- Handling PDF text extraction.
- Fixing Groq API authentication issues.
- Improving prompt quality for better AI responses.

## What I Learned

- How to integrate Groq API with Streamlit.
- How to extract text from PDF files using PyPDF.
- Importance of prompt engineering for accurate AI-generated explanations.
- Error handling and debugging API authentication issues.

## Future Improvements

- Support image-based medical reports using OCR.
- Add multilingual support.
- Generate downloadable PDF summaries.
- Improve UI and add report history.
